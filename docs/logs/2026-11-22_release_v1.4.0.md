## 1. Mục Tiêu & Điểm Nổi Bật Bản Phát Hành (Release Highlights)

Bản phát hành **v1.4.0** mang đến bản nâng cấp đột phá cho VNPT Ping Tool với bộ công cụ **Wi-Fi Inspector & Password Auditor**:

1. **Tab Quét mạng mới (Wi-Fi Inspector & Security Analyzer)**:
   - Quét và liệt kê danh sách Access Point Wi-Fi xung quanh (2.4GHz, 5GHz, 6GHz).
   - Phân loại và đánh giá chuẩn bảo mật: WPA3 SAE, WPA2 PSK, Enterprise, WEP và Mạng mở (Open).
   - Tương tác thông minh: Bấm vào thẻ Wi-Fi để mở rộng xem chi tiết đánh giá bảo mật và chuỗi capabilities.
   - Lối tắt trực tiếp dưới dòng đánh giá bảo mật để chuyển sang kiểm định mật khẩu (`Audit`).
   - Nút "Quét lại" được bố trí căn phải trong thẻ **PHÂN TÍCH TỔNG QUAN** trực quan và tự nhiên.

2. **Password Auditor cấp độ khó 1-99**:
   - Tích hợp sẵn tập từ điển 1.684 mẫu mật khẩu phổ thông phân cấp từ 1 đến 99.
   - Tái cấu trúc file JSON theo định dạng nhóm `{ level, type, passwords: [...] }` tối ưu dung lượng (giảm hơn 75% số dòng code) và đồng bộ trực tiếp với bộ lọc ký tự (Number, Number + String, Complex).
   - Thanh trượt Slider kéo độ khó 1..99 trên Compose với nhãn phân cấp màu động (Rất dễ -> Rất khó).
   - Thuật toán quét tuần tự theo cấp độ tăng dần, tự động dừng ngay khi phát hiện khớp hoặc khi người dùng tạm dừng.

3. **Lưu trữ Log & Màn hình xem mật khẩu đã khớp**:
   - Tự động lưu trữ lịch sử các mạng bị trùng mật khẩu vào bộ nhớ bền vững `PingStorage`.
   - Hộp thoại modal `PasswordAuditHistoryDialog` chuẩn Liquid Glass x Apple Music HIG với tính năng sao chép mật khẩu 1 chạm và quản lý bản ghi.

4. **100% Zero Ads & OTA Auto-Update**:
   - Cam kết tuyệt đối không quảng cáo.
   - Cơ chế tự động kiểm tra và tải cập nhật OTA trực tiếp từ GitHub Releases.

## 2. Quy Trình Triển Khai (Execution Steps)

1. **Pre-flight Checks**:
   - Chạy `./gradlew.bat compileDebugKotlin` -> `BUILD SUCCESSFUL`.
2. **Bump Version**:
   - Cập nhật `app/build.gradle.kts`: `versionCode = 10`, `versionName = "1.4.0"`.
3. **Assemble Release APK & Signing**:
   - Chạy `./gradlew.bat assembleRelease` -> Tạo file APK release có chữ ký số tại `release-artifacts/PingTool-v1.4.0.apk`.
4. **Git Commit & Tag**:
   - Commit: `chore(release): bump version to v1.4.0` (`ec18547`).
   - Annotated Tag: `v1.4.0`.
5. **Publish to GitHub**:
   - Đẩy commit và tag `v1.4.0` lên remote `origin main`.
   - Sử dụng GitHub CLI (`gh release create`) tải file APK trực tiếp lên GitHub Releases.
